# 官方社区插件

这些可选功能由 Covel 官方维护，通过社区安装流程安装和授权，不再随 Covel 主仓内置分发。

| 插件                                              | 用途                | 示例重点                                     |
| ------------------------------------------------- | ------------------- | -------------------------------------------- |
| [DashScope Images](dashscope-image-gen/README.md) | 万相剧情插图        | 多 runtime、工具事件、后台生成、图片下载权限 |
| [OpenAI Images](openai-image-gen/README.md)       | OpenAI 兼容剧情插图 | 统一图像管线、设置、持久化画廊               |
| [MiMo TTS](mimo-tts/README.md)                    | 自动和手动朗读      | 自定义 speech wire、后台回合任务、音轨 UI    |

复杂开发示例见 [Jev 选项推荐](../examples/jev-choice-demo/README.md)；入门示例见 [Story Note](../examples/story-note/README.md)。安装链接在根 README 的生成表格中。
